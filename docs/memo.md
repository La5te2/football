# Jackaroo 训练改进备忘

本文记录 Jackaroo 下一阶段的候选改动和实施顺序。内容服务于方案讨论与实现检查，完成实现后再转写为现状说明。

## 1. 保持单人控制

Jackaroo 继续在每个决策步控制引擎指定的一名球员，其余球员由引擎的 TeamAI 和 Eliza 控制。单人控制减少了策略直接输出的动作数量，同时策略仍需从公开观察中理解其余球员的运动及其对局面的影响。因此，单人控制带来较低的输出维度，状态建模则保留多球员环境的复杂性。

当前阶段保留该边界。训练模块学习如何在既有球队行为中控制指定球员，TeamAI 和 Eliza 继续承担其余球员的球队协作与个体行为。

## 2. Segment 定义

一个 segment 从开球开始，在任意一方攻入下一粒进球时结束。己方进球产生 $+1$，对方进球产生 $-1$。完整比赛到达时间上限时，最后一个随比赛终止而结束的尾段从 PPO 数据中丢弃。

行为克隆读取完整教师比赛中的全部有效决策步。PPO 按进球 segment 组织轨迹，并以折扣因子 $1$ 将该 segment 的最终结果赋给其中每个动作。文档将进球结束的轨迹称为“进球 segment”，将比赛时间上限截断的最后一段称为“终场尾段”。

比赛时钟和引擎步数继续控制引擎演化与完整比赛终止。策略输入由当前局面的实体状态组成；环境保留累计比分，用于识别进球、记录完整比赛结果和输出评估统计。

现有 TeamAI 会根据累计比分、比赛时间和近期控球情况调整球队进攻倾向。Jackaroo 通过球员状态、动态阵型和实际运动观察这些调整的外显结果，累计比分与比赛时间由此成为环境的隐藏条件。这项设定形成部分可观测决策过程；持久时间状态负责从连续局面中估计 TeamAI 的当前倾向和相关隐藏条件。

## 3. 一个 Run 使用一个固定 Seed

一次完整训练 run 使用一个固定的引擎 seed。该 run 内所有环境在重置完整比赛时复用这个 seed；并行环境通过策略的独立动作采样产生各异的轨迹。下一次从头开始的 run 可以使用另一个 seed。

从训练开始到 Jackaroo 稳定赢得比赛，整个 run 都属于固定-seed 阶段。训练期间同时保留一组专用于评估的固定 seeds，用于区分训练 seed 上的进步与跨 seed 的泛化。Jackaroo 在训练 seed 上稳定获胜后，再设计多 seed 训练阶段。

该改动集中在训练环境的重置策略。引擎继续采用原有的确定性 seed 行为、模型接口和比赛规则。

## 4. 持久的实体级时间状态

当前网络每次根据最近若干帧重新计算一个临时时间表示。候选实现改为给每名球员、球和全局局面保存跨步骤隐藏状态。每名球员的隐藏状态始终附着于该球员；指定控制球员发生变化后，各球员的历史继续保持原有的身份对应关系。进球 segment 结束时清空全部策略隐藏状态。

所有球员共享同一套时间状态更新参数。每名球员在运行时保存各自的状态值，因此模型能够利用球员身份的连续性，同时将参数规模维持在一套时间状态更新器的水平。

PPO 将按固定长度的连续序列组成 minibatch。每个序列保存起始隐藏状态和边界 mask，使用 truncated backpropagation through time 训练；每条序列完整位于单个 segment 内。候选初始配置为实体隐藏宽度 64、全局隐藏宽度 256、反向传播序列长度 32。最终参数根据吞吐量和显存测试确定。

## 5. 内生的动作条件足球空间控制博弈模型

这里的足球空间理论以空间控制和对抗双方的博弈逻辑为核心。模型读取公开实体状态，理解受控球员的动作怎样引起队友和对手的响应，怎样改变双方对空间的控制关系，以及新的空间关系怎样影响后续动作和下一粒进球。该表示在策略网络内部形成，成为 Jackaroo 理解球队互动、空间创造和机会利用的内生能力。

因此，模型需要学习以下因果链：

$$
\text{受控球员动作}
\rightarrow
\text{其他球员响应}
\rightarrow
\text{空间控制关系变化}
\rightarrow
\text{新的可行动作}
\rightarrow
\text{下一粒进球的概率变化}.
$$

例如，向边路转移球权可以吸引防守球员横向移动，使原有防守区域出现空缺；当球再次进入该区域且己方球员能够接应时，这次转移便形成有效推进。模型从连续状态和最终进球结果中学习这种牵制、空间创造和后续利用关系，并根据具体局面形成相应的传球倾向。

### 5.1 单控制球员的决策节点

`designated` 球员在网络中充当当前决策节点。Jackaroo 通过这名球员的动作对比赛施加一次干预，同时把其余二十一名球员和球视为共同构成当前博弈状态的实体。TeamAI、Eliza 和对方策略对这次干预作出响应，并通过后续公开观察反馈给 Jackaroo。

Transformer 编码二十二名球员和球之间的控制、牵制、接应、封锁及阵型关系。当前 `designated` 球员使用自身实体状态查询这一全局关系表示，再评价现有的三十二个原子动作。当控制对象从球员 A 变为球员 B 时，决策查询点随之转移，各实体的持久时间状态继续附着于原球员，此前形成的防线移动、跑动趋势和空间变化也随之延续。

### 5.2 空间控制、可利用性与进球价值

模型可以把空间博弈表示因子化为三个相互关联的内部量：

$$
C_t(x)=P(\text{我方先控制位置 }x\mid s_t),
$$

$$
R_t(x)=P(\text{球能够到达 }x\text{ 且己方能够接应}\mid s_t),
$$

$$
V_t(x)=\mathbb{E}[G\mid s_t,\text{我方在 }x\text{ 控球}],
$$

其中 $G\in\{-1,+1\}$ 表示当前进球 segment 最终由哪一方取得下一粒进球。$C_t$ 描述空间控制，$R_t$ 描述该空间通过传球、带球和接应得到利用的可能性，$V_t$ 描述利用该空间对下一粒进球的长期价值。这些量作为策略网络内部的可学习表示和辅助预测目标；PPO 的策略目标继续来自实际进球 segment 的结果。

### 5.3 动作条件的空间响应

策略评价动作时同时考虑动作执行前的局面以及动作可能引起的空间变化。候选实现使用当前实体关系、`designated` 球员状态和结构化动作表示，预测短期空间响应：

$$
\hat z_{t+h}^{(a)}=F_\theta\left(z_t,h_t^{\mathrm{designated}},e_a\right).
$$

策略头再根据当前状态、候选动作以及预测的关系变化计算动作 logit：

$$
\ell_t(a)=H_\theta\left(h_t^{\mathrm{designated}},e_a,\hat z_{t+h}^{(a)}-z_t\right).
$$

引擎根据方向动作、传球类型、当前局面和连续决策共同确定传球意图与接收者。因此，动作模型需要共享方向和足球功能的结构，并利用持久时间状态理解跨步骤的动作意图。

一次实际轨迹提供已执行动作的后续结果，其余候选动作共同构成该状态的反事实空间。第一版空间响应模型作为辅助表示学习任务，使用球位置、下一名触球队员、球权变化和球员短期位移等逐步产生的监督信号。预测在保留轨迹上达到预定精度以后，策略头再显式使用其预测变化，使真实引擎反馈持续主导策略学习。

这种表示借鉴了足球分析中的空间控制、空间创造和下一进球价值概念。[Wide Open Spaces](https://www.lukebornn.com/papers/fernandez_ssac_2018.pdf) 区分了球员直接占据空间与通过牵制对手为队友创造空间；[Expected Possession Value](https://arxiv.org/abs/2011.09426) 用完整时空状态估计下一粒进球的价值；[TacticAI](https://www.nature.com/articles/s41467-024-45965-x) 展示了球员关系图和球场对称性对足球小样本建模的作用。Jackaroo 使用这些思想组织网络的观察方式，同时仍由实际环境交互学习当前黑盒 TeamAI、Eliza 和对手的响应规律。

## 6. 结构化动作表示

当前动作头把每个动作表示为独立类别。候选动作头为每个动作提供结构化表示：八个移动方向使用二维方向向量；足球功能动作具有功能类型表示；持续动作的按下与释放共享按钮身份并使用各自的阶段表示。

策略状态与动作表示共同计算每个动作的 logit。这样可以让相邻方向、同一按钮的按下与释放以及同类足球功能共享统计信息，同时继续输出现有的离散动作编号并保持现有引擎动作接口。

## 7. KL 约束

每个 PPO epoch 后计算新旧策略之间的近似 KL 散度。当累计更新超过目标范围时，提前结束当前 PPO update 的剩余 epoch。候选目标值为 $0.02$，候选停止阈值为 $0.025$；实际阈值根据固定评估结果调整。

KL 约束限制一次 update 对策略的改动幅度。奖励和 segment 回报保持原有定义，同时降低多次重复使用同一批 rollout 时发生策略突变的风险。

## 8. 可行性与预期收益

固定 seed、删除累计比分和 KL early stopping 都位于训练模块内部，实现范围小，引擎和模型插件接口继续保持现状。固定 seed 和 KL early stopping 适合作为第一组改动。删除累计比分符合以进球 segment 为目标的策略语义；同时，TeamAI 会读取比分和比赛时间，因此这项改动需要作为有意采用的部分可观测设定单独评估。

结构化动作表示集中改变策略网络的动作头，并保持 32 动作接口。新架构使用对应的新 checkpoint 格式。

持久时间状态需要同时修改网络、rollout 存储和 PPO minibatch 组织，是本计划中实现风险最高的部分。持久化继续共享同一套循环网络参数；按序列训练还可以消除重叠历史窗口对同一帧的重复编码。实际速度取决于序列长度、padding 比例和 GPU 批处理效率，需要用每秒模拟步数、每秒 PPO transition 数和显存占用验证。

内生的动作条件足球空间控制博弈模型需要修改实体编码、动作表示、辅助预测任务和策略特征组合，并以公开观察作为全部输入。TeamAI、Eliza、物理和比赛规则继续提供原有环境行为。其主要风险包括模型复杂度超过现有样本量，以及单条轨迹仅能直接监督实际执行动作的结果。因此，第一版先学习实际发生的球员响应和空间关系变化，再逐步让策略使用动作条件预测，并通过固定-seed 学习曲线和保留轨迹预测误差判断收益。

预期收益分为三类：固定 seed 和 KL 约束降低早期训练方差；持久实体状态提高动作连续性和跨控制对象的时间建模能力；空间控制博弈模型与结构化动作表示让策略围绕“动作如何改变全场关系”共享有限样本中的规律。上述收益都需要通过相同训练 seed、相同评估 seeds 和相同模拟步数下的对照结果确认。

## 9. 实施顺序

1. 统一 segment 术语，删除策略输入中的累计比分。
2. 让一个完整 run 固定使用一个训练 seed，并保留独立的固定评估 seeds。
3. 加入 KL early stopping，先稳定现有 PPO。
4. 实现结构化动作表示。
5. 将当前短窗口 GRU 改为按 segment 重置的持久时间状态，并将 PPO 改为连续序列训练。
6. 在持久实体状态之上加入球位置、下一触球者、球权变化和球员短期位移等辅助预测任务。
7. 加入以 `designated` 球员为决策节点的动作条件空间响应模型，并先将其用于辅助表示学习。
8. 在保留轨迹上验证空间响应预测以后，让策略头显式使用预测的关系变化。
9. 比较每一步改动后的训练吞吐量、segment 进球比例和固定-seed 评估结果，再据此确定网络扩展规模。
